3. **SiteForge**
   - *Classification:* Developer Tool · Framer Plugin
   - *Domain:* Design-to-Code Automation
   - *Summary:* Framer designer plugin that traverses and inspects frame trees via the Framer Plugin API to generate structured React and Tailwind CSS layout scaffolding, accelerating front-end translation.

4. **ESP32 Fire & Gas Alarm System**
   - *Classification:* Hardware & Firmware Prototype
   - *Domain:* Embedded Systems & Safety Monitoring
   - *Summary:* Multi-sensor physical prototype combining MQ-2 gas/smoke detection and optical flame sensing with an ESP32 microcontroller running FreeRTOS-based task scheduling for real-time acoustic buzzer and visual LED status alerts.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm (v9 or higher recommended)

### Installation

Clone the repository and install dependencies:

```bash
npm install
```

### Development Server

Start the local Vite development server:

```bash
npm run dev
```

The application will be available at `http://localhost:3000`.

---

## Quality & Verification

Run static type-checking and production build verification:

```bash
# Type-check TypeScript sources
npm run lint

# Compile production bundle
npm run build
```

Production output will be generated in the `dist/` directory.
